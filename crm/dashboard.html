ตาราง: ข้อมูลรายคน

ชื่อที่แสดงField Nameสูตร / ที่มาแหล่ง
IDmember_id—member_report
ชื่อfull_name—member_report
กลุ่มวงจรชีวิตlifecycle_segment—member_report
จำนวนซื้อใน 1 เดือนแรกorders_first_1mCOUNT(bills) WHERE Close_Date ≤ register_date + 30 วันmember_report
จำนวนซื้อใน 6 เดือนแรกorders_first_6mCOUNT(bills) WHERE Close_Date ≤ register_date + 180 วันmember_report

จำนวนบิลทั้งหมดtotal_orders_lifetimeCOUNT(bills) ทั้งหมดmember_report

AOVaovtotal_spend_lifetime ÷ total_orders_lifetimeคำนวณ

กำไรprofitSUM(net_profit) บิลสำเร็จbill_report

สูตรคำนวณ CLV (ระดับรวม)

  • orders_first_1m = COUNT(bills) WHERE Close_Date ≤ register_date + 30 วัน
  • orders_first_6m = COUNT(bills) WHERE Close_Date ≤ register_date + 180 วัน
  • orders_first_1y = COUNT(bills) WHERE Close_Date ≤ register_date + 365 วัน
  • total_orders_lifetime = COUNT(bills) ทั้งหมดของสมาชิก
  • total_spend_lifetime = SUM(Total_Net_Sales) ของสมาชิก
  • aov = total_spend_lifetime / total_orders_lifetime
  • cost = SUM(total_cost) จากบิลสำเร็จของสมาชิก
  • profit = SUM(net_profit) จากบิลสำเร็จของสมาชิก
  • sum_orders_first_1m = SUM(orders_first_1m) ของสมาชิกที่ ≠ Churn
  • avg_orders_first_1m = AVG(orders_first_1m) ของสมาชิกที่ ≠ Churn
  • sum_orders_first_6m = SUM(orders_first_6m) ของสมาชิกที่ ≠ Churn
  • avg_orders_first_6m = AVG(orders_first_6m) ของสมาชิกที่ ≠ Churn
  • sum_orders_first_1y = SUM(orders_first_1y) ของสมาชิกที่ ≠ Churn
  • avg_orders_first_1y = AVG(orders_first_1y) ของสมาชิกที่ ≠ Churn
  • sum_total_orders_lifetime = SUM(total_orders_lifetime) ของสมาชิกที่ ≠ Churn
  • avg_total_orders_lifetime = AVG(total_orders_lifetime) ของสมาชิกที่ ≠ Churn
  • sum_total_spend = SUM(total_spend_lifetime) ของสมาชิกที่ ≠ Churn
  • avg_aov = sum_total_spend / sum_total_orders_lifetime
  • spend_per_customer_lifetime = sum_total_spend / จำนวนสมาชิก (ที่ ≠ Churn)
  • sum_profit = SUM(profit) ของสมาชิกที่ ≠ Churn
  • avg_profit_per_order = sum_profit / sum_total_orders_lifetime
  • profit_per_customer_lifetime = sum_profit / จำนวนสมาชิก (ที่ ≠ Churn)

ส่วนที่ 3: ยอดซื้อจากสมาชิกในสาขา

สาขา bill_report

📋
เงื่อนไขพื้นฐาน: bill_status = "สำเร็จ" + payment_method ≠ "ไม่คิดรายได้" + Filter วันที่จากหน้าบ้าน + เฉพาะสาขาที่เลือก

การ์ด: ยอดซื้อ

ชื่อที่แสดงField Nameสูตรเงื่อนไขเพิ่มเติม
ยอดซื้อจากสมาชิกmember_sales_totalSUM(Total_Net_Sales)+ customer_phone = true
ยอดซื้อทั้งหมดall_customer_sales_totalSUM(Total_Net_Sales)ไม่จำกัดสมาชิก
% ยอดซื้อสมาชิกmember_sales_percentage(member_sales_total ÷ all_customer_sales_total) × 100—
ยอดซื้อช่วงก่อนmember_sales_prevSUM(Total_Net_Sales) ช่วงก่อนหน้าตาม Filter วันที่
% เปลี่ยนแปลงmember_sales_mom_percentage((member_sales_total - member_sales_prev) ÷ member_sales_prev) × 100ถ้าติดลบ = ลูกศรลง
  • member_sales_total = SUM(Total_Net_Sales) WHERE customer_phone = true
  • all_customer_sales_total = SUM(Total_Net_Sales) ทั้งหมด (ไม่จำกัดสมาชิก)
  • member_sales_percentage = (member_sales_total / all_customer_sales_total) × 100
  • member_sales_mom_percentage = ((member_sales_total - member_sales_prev) / member_sales_prev) × 100

การ์ด: จำนวนบิล

ชื่อที่แสดงField Nameสูตรเงื่อนไข
จำนวนบิลทั้งหมดtotal_bills_countCOUNT(Receipt_No)ทุกสถานะ (รวมทั้งหมด)
บิลสำเร็จbills_completed_countCOUNT(Receipt_No)bill_status = "สำเร็จ"
บิลคืนเงินbills_refund_countCOUNT(Receipt_No)bill_status = "คืนเงิน"
บิลยกเลิกbills_cancel_countCOUNT(Receipt_No)bill_status = "ยกเลิก"

การ์ด: ค่าเฉลี่ย

ชื่อที่แสดงField Nameสูตรเงื่อนไข
ยอดซื้อเฉลี่ยต่อบิลavg_sales_per_billmember_sales_total ÷ bills_completed_countสำเร็จ + คิดรายได้
เฉลี่ยต่อบิลช่วงก่อนavg_sales_per_bill_prevmember_sales_prev ÷ bills_completed_count (ช่วงก่อน)ตาม Filter
% เปลี่ยนแปลงavg_sales_per_bill_mom_percentage((avg - avg_prev) ÷ avg_prev) × 100—
  • avg_sales_per_bill = member_sales_total / bills_completed_count
  • avg_sales_per_bill_mom_percentage = ((avg_sales_per_bill - avg_sales_per_bill_prev) / avg_sales_per_bill_prev) × 100

การ์ด: TC & TA

ชื่อที่แสดงField Nameสูตรเงื่อนไข
จำนวนลูกค้า (TC)total_customers_countSUM(customer_count)สำเร็จ + คิดรายได้ (นับทุกคน ไม่จำกัดสมาชิก)
TC ช่วงก่อนtotal_customers_count_prevSUM(customer_count) ช่วงก่อนตาม Filter
% เปลี่ยนแปลง TCtotal_customers_mom_percentage((TC - TC_prev) ÷ TC_prev) × 100—
เฉลี่ยต่อหัว (TA)avg_spend_per_customermember_sales_total ÷ active_members_count—
TA ช่วงก่อนavg_spend_per_customer_prevคำนวณเดียวกันแต่ช่วงก่อนตาม Filter
% เปลี่ยนแปลง TAavg_spend_per_customer_percentage((TA - TA_prev) ÷ TA_prev) × 100—
จำนวนสมาชิกที่เข้าใช้บริการactive_members_countCOUNT(DISTINCT customer_phone)เฉพาะเบอร์ที่มีระดับสมาชิก + สำเร็จ + คิดรายได้
  • total_customers_count = SUM(customer_count) จากบิลสำเร็จ + คิดรายได้
  • total_customers_mom_percentage = ((total_customers_count - total_customers_count_prev) / total_customers_count_prev) × 100
  • active_members_count = COUNT(DISTINCT customer_phone) WHERE มีระดับสมาชิก
  • avg_spend_per_customer = member_sales_total / active_members_count
  • avg_spend_per_customer_percentage = ((avg_spend_per_customer - avg_spend_per_customer_prev) / avg_spend_per_customer_prev) × 100
💡
TC vs active_members_count:
• TC = จำนวนลูกค้าทั้งหมด (รวมทุกคนที่นั่งในบิล ไม่จำเป็นต้องเป็นสมาชิก)
• active_members_count = จำนวนสมาชิกที่ไม่ซ้ำกัน (เฉพาะเบอร์ที่มีระดับสมาชิก)

ส่วนที่ 4.2: การแบ่งกลุ่มลูกค้า

Owner member_report

RFM Segmentation

📊
กลุ่ม RFM
Field ที่ใช้: member_id, total_spend_lifetime, total_orders_lifetime, last_visit_date, recency_day
ข้อมูลที่แสดงสูตร
ชื่อกลุ่ม RFMจาก rfm_segment
จำนวนสมาชิกCOUNT(สมาชิก) WHERE rfm_segment = กลุ่มนั้น
สัดส่วนจากทั้งหมด (%)จำนวนในกลุ่ม ÷ จำนวนสมาชิกทั้งหมด × 100
  • จำนวนสมาชิก RFM = COUNT(สมาชิก) WHERE rfm_segment = "ชื่อกลุ่ม"
  • สัดส่วน (%) = (จำนวนในกลุ่ม / จำนวนสมาชิกทั้งหมด) × 100

กลุ่มวงจรชีวิต (Lifecycle)

🔄
Lifecycle Segment
ปัจจัย: Recency (TODAY() - last_visit_date) + Frequency (total_orders) | บิลสำเร็จ + คิดรายได้
ข้อมูลที่แสดงสูตร
ชื่อกลุ่ม Lifecycleจาก lifecycle_segment
จำนวนสมาชิกCOUNT(สมาชิก) WHERE lifecycle_segment = กลุ่มนั้น
สัดส่วนจากทั้งหมด (%)จำนวนในกลุ่ม ÷ จำนวนสมาชิกทั้งหมด × 100
  • จำนวนสมาชิก Lifecycle = COUNT(สมาชิก) WHERE lifecycle_segment = "ชื่อกลุ่ม"
  • สัดส่วน (%) = (จำนวนในกลุ่ม / จำนวนสมาชิกทั้งหมด) × 100

ระดับสมาชิก / แท็ก / สาขาที่สมัคร

🏅
ระดับสมาชิก, แท็ก, สาขาที่สมัคร
ใช้สูตรเดียวกัน แค่เปลี่ยน field ที่ GROUP BY
ประเภทField ที่ใช้สูตร
ระดับสมาชิกmember_tierCOUNT GROUP BY member_tier
แท็กtagsCOUNT GROUP BY tags
สาขาที่สมัครregister_branchCOUNT GROUP BY register_branch

สัดส่วน (%) = จำนวนในกลุ่ม ÷ จำนวนทั้งหมด × 100

  • จำนวนสมาชิกแต่ละกลุ่ม = COUNT(สมาชิก) GROUP BY [member_tier / tags / register_branch]
  • สัดส่วน (%) = (จำนวนในกลุ่ม / จำนวนสมาชิกทั้งหมด) × 100
