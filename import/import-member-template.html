1. ภาพรวม

ระบบรองรับการ Import ข้อมูลสมาชิกใหม่แบบ Bulk ผ่านไฟล์ Excel (.xlsx) เพื่อให้สามารถเพิ่มสมาชิกจำนวนมากได้ในคราวเดียว โดยไม่ต้องสร้างทีละรายการในระบบ

new_releases
สร้างใหม่เท่านั้น (Create Only): การ Import นี้ใช้สำหรับสร้างสมาชิกใหม่เท่านั้น ไม่รองรับการอัพเดทข้อมูลสมาชิกที่มีอยู่แล้วในระบบ หากเบอร์โทรศัพท์ซ้ำกับสมาชิกเดิม ระบบจะแสดง Error
info
วัตถุประสงค์: ลดเวลาในการสร้างสมาชิกใหม่จำนวนมาก เช่น การย้ายข้อมูลจากระบบเดิม หรือการนำเข้าสมาชิกจากแคมเปญ

2. โครงสร้างคอลัมน์ใน Template

ตารางด้านล่างแสดงคอลัมน์ทั้งหมดที่อยู่ใน Template พร้อมระบุประเภทข้อมูลและเงื่อนไข

# ชื่อคอลัมน์ บังคับ ประเภท หมายเหตุ
1 ชื่อ-นามสกุล ไม่บังคับ Text ชื่อและนามสกุลของสมาชิก
2 ชื่อเล่น ไม่บังคับ Text ชื่อเล่น
3 เบอร์โทรศัพท์ ✱ บังคับ Text (ตัวเลข 10 หลัก) Key หลัก — ห้ามซ้ำ, ไม่มีขีด
4 อีเมล ไม่บังคับ Text (Email) ต้องอยู่ในรูปแบบ email ที่ถูกต้อง
5 วันเกิด ไม่บังคับ Date (DD/MM/YYYY) ต้องไม่เป็นวันในอนาคต
6 เพศ ไม่บังคับ 📋 ตัวเลือก ชาย, หญิง, ไม่ระบุ
7 บ้านเลขที่ ไม่บังคับ Text ที่อยู่ - บ้านเลขที่
8 จังหวัด ไม่บังคับ Text (พิมพ์เอง) ต้องตรงกับรายชื่อจังหวัดในระบบ
9 เขต/อำเภอ ไม่บังคับ Text (พิมพ์เอง) ต้องตรงกับข้อมูลในระบบ + อยู่ภายใต้จังหวัดที่ระบุ
10 แขวง/ตำบล ไม่บังคับ Text (พิมพ์เอง) ต้องตรงกับข้อมูลในระบบ + อยู่ภายใต้เขต/อำเภอที่ระบุ
11 ไปรษณีย์ ไม่บังคับ Text (ตัวเลข 5 หลัก) รหัสไปรษณีย์
12 อาชีพ ไม่บังคับ 📋 ตัวเลือก ดูตัวเลือกในหัวข้อ 3
13 รายได้ ไม่บังคับ 📋 ตัวเลือก ดูตัวเลือกในหัวข้อ 3
14 สถานะภาพ ไม่บังคับ 📋 ตัวเลือก ดูตัวเลือกในหัวข้อ 3
15 ระดับการศึกษา ไม่บังคับ 📋 ตัวเลือก ดูตัวเลือกในหัวข้อ 3
16 การรับข้อมูลข่าวสาร ไม่บังคับ 📋 ตัวเลือก ดูตัวเลือกในหัวข้อ 3
17 ไลฟ์สไตล์ ไม่บังคับ Text ระบุข้อความอิสระ
18 อาหารที่แพ้ ไม่บังคับ Text ระบุข้อความอิสระ
19 อาหารที่ไม่ทาน ไม่บังคับ Text ระบุข้อความอิสระ
20 คะแนนคงเหลือ ไม่บังคับ Number (จำนวนเต็ม) ไม่ใส่ = 0
21 คะแนนสะสม ไม่บังคับ Number (จำนวนเต็ม) ไม่ใส่ = 0
22 ยอดใช้จ่ายสะสม ไม่บังคับ Number (ทศนิยม 2 ตำแหน่ง) ไม่ใส่ = 0
23 วันสมัครสมาชิก ไม่บังคับ Date (DD/MM/YYYY) วันที่สมัครสมาชิก
24 ระดับ Rank ไม่บังคับ Text (พิมพ์เอง) ต้องตรงกับระดับ Rank ที่ตั้งค่าไว้ในระบบ

3. ข้อมูลที่เป็นตัวเลือก (Dropdown)

คอลัมน์ที่มีเครื่องหมาย 📋 ตัวเลือก ต้องใส่ค่าตรงตัวตามรายการที่ระบบรองรับเท่านั้น ห้ามใส่ค่าอื่นที่ไม่อยู่ในรายการ

person เพศ

ชาย หญิง ไม่ระบุ

work อาชีพ

พนักงานบริษัท ข้าราชการ ธุรกิจส่วนตัว นักเรียน/นักศึกษา อื่นๆ

payments รายได้

น้อยกว่า 15,000 บาท 15,000 - 30,000 บาท 30,001 - 50,000 บาท มากกว่า 50,000 บาท

favorite สถานะภาพ

โสด สมรส หม้าย หย่า

school ระดับการศึกษา

ต่ำกว่ามัธยม มัธยม ปวช./ปวส. ปริญญาตรี ปริญญาโท ปริญญาเอก อื่นๆ

notifications การรับข้อมูลข่าวสาร

Line SMS Email ไม่รับข่าวสาร
warning
สำคัญ: ค่าที่ใส่ต้องตรงตัวอักษรตามรายการด้านบน (case-sensitive) หากใส่ค่าที่ไม่ตรง ระบบจะแสดง Error

4. กฎการ Import ข้อมูล

verified 4.1 คอลัมน์บังคับกรอก

  • เบอร์โทรศัพท์ — ต้องมีค่าทุกแถว (ใช้เป็น Key หลักในการระบุตัวตนสมาชิก)

remove_circle_outline 4.2 การไม่ใส่ข้อมูล (Empty Value)

  • ข้อมูลประเภท Number (คะแนน, ยอดใช้จ่าย) → ค่าในระบบจะเป็น 0
  • ข้อมูลประเภท Text / Date → ค่าในระบบจะเป็นค่าว่าง (empty)

phone_android 4.3 เงื่อนไขเบอร์โทรศัพท์

  • รูปแบบ: 0XXXXXXXXX (ตัวเลข 10 หลัก ไม่มีขีด เช่น 0901234567)
  • ต้องขึ้นต้นด้วย 0
  • ห้ามมีตัวอักษร สัญลักษณ์ หรือขีด -
  • ห้ามซ้ำกับเบอร์โทรศัพท์อื่นในไฟล์เดียวกัน
  • ห้ามซ้ำกับเบอร์โทรศัพท์ที่มีอยู่ในระบบแล้ว

mail 4.4 เงื่อนไขอีเมล

  • ต้องเป็นรูปแบบ Email ที่ถูกต้อง (มี @ และ domain)
  • หากไม่ใส่ ระบบจะเก็บเป็นค่าว่าง

calendar_month 4.5 เงื่อนไขวันที่

  • รูปแบบ: DD/MM/YYYY เท่านั้น
  • ต้องเป็นวันที่จริง (เช่น ไม่มี 31/02/2026)
  • วันเกิดต้องไม่เป็นวันในอนาคต

location_on 4.6 เงื่อนไขที่อยู่

  • จังหวัด, เขต/อำเภอ, แขวง/ตำบล เป็นการพิมพ์เอง แต่ค่าที่ใส่ต้องตรงกับข้อมูลในระบบ
  • จังหวัดต้องตรงกับรายชื่อจังหวัดในระบบ
  • เขต/อำเภอ ต้องอยู่ภายใต้จังหวัดที่ระบุ
  • แขวง/ตำบล ต้องอยู่ภายใต้เขต/อำเภอที่ระบุ
  • หากระบุเขต/อำเภอ โดยไม่ระบุจังหวัด → Error
  • หากระบุแขวง/ตำบล โดยไม่ระบุเขต/อำเภอ → Error
  • รหัสไปรษณีย์ต้องเป็นตัวเลข 5 หลัก

star 4.7 เงื่อนไขคะแนนและยอดใช้จ่าย

  • คะแนนคงเหลือ / คะแนนสะสม → จำนวนเต็ม ≥ 0
  • ยอดใช้จ่ายสะสม → ตัวเลข ≥ 0 (ทศนิยม 2 ตำแหน่ง)

military_tech 4.8 เงื่อนไขระดับ Rank

  • ค่าที่ใส่ต้องตรงกับชื่อระดับ Rank ที่ตั้งค่าไว้ในระบบ
  • หากไม่ใส่ค่า ระบบจะเก็บเป็นค่าว่าง (ไม่กำหนด Rank)

5. รายการ Error Messages

เมื่อข้อมูลไม่ผ่านการตรวจสอบ ระบบจะแจ้งเตือน Error พร้อมระบุแถวที่พบปัญหา

error
หลักการ All or Nothing: หากพบ Error แม้แต่ 1 รายการ ระบบจะไม่ทำการ Import ข้อมูลทั้งไฟล์ และแสดง Error ทั้งหมดให้แก้ไข
รหัส เงื่อนไข ข้อความแจ้งเตือน
ERR-001 เบอร์โทรศัพท์เป็นค่าว่าง แถวที่ {row}: กรุณาระบุเบอร์โทรศัพท์ (เบอร์โทรศัพท์เป็นข้อมูลบังคับ)
ERR-002 เบอร์โทรศัพท์รูปแบบไม่ถูกต้อง แถวที่ {row}: รูปแบบเบอร์โทรศัพท์ไม่ถูกต้อง (ต้องเป็นตัวเลข 10 หลัก ไม่มีขีด)
ERR-003 เบอร์โทรศัพท์ซ้ำในไฟล์ แถวที่ {row}: เบอร์โทรศัพท์ "{phone}" ซ้ำกับแถวที่ {duplicate_row}
ERR-004 เบอร์โทรศัพท์ซ้ำกับในระบบ แถวที่ {row}: เบอร์โทรศัพท์ "{phone}" มีอยู่ในระบบแล้ว
ERR-005 อีเมลรูปแบบไม่ถูกต้อง แถวที่ {row}: รูปแบบอีเมลไม่ถูกต้อง
ERR-006 วันที่รูปแบบไม่ถูกต้อง แถวที่ {row}: รูปแบบวันที่ในคอลัมน์ "{column_name}" ไม่ถูกต้อง (ต้องเป็น DD/MM/YYYY)
ERR-007 วันเกิดเป็นวันในอนาคต แถวที่ {row}: วันเกิดต้องไม่เป็นวันที่ในอนาคต
ERR-008 ค่าตัวเลือกไม่ตรงกับที่ระบบรองรับ แถวที่ {row}: ค่า "{value}" ในคอลัมน์ "{column_name}" ไม่ตรงกับตัวเลือกที่รองรับ
ERR-009 จังหวัดไม่มีในระบบ แถวที่ {row}: ไม่พบจังหวัด "{province}" ในระบบ
ERR-010 เขต/อำเภอไม่ตรงกับจังหวัด แถวที่ {row}: เขต/อำเภอ "{district}" ไม่อยู่ภายใต้จังหวัด "{province}"
ERR-011 แขวง/ตำบลไม่ตรงกับเขต/อำเภอ แถวที่ {row}: แขวง/ตำบล "{sub_district}" ไม่อยู่ภายใต้เขต/อำเภอ "{district}"
ERR-012 ระบุเขต/อำเภอโดยไม่ระบุจังหวัด แถวที่ {row}: กรุณาระบุจังหวัดก่อนระบุเขต/อำเภอ
ERR-013 ระบุแขวง/ตำบลโดยไม่ระบุเขต/อำเภอ แถวที่ {row}: กรุณาระบุเขต/อำเภอก่อนระบุแขวง/ตำบล
ERR-014 รหัสไปรษณีย์ไม่ใช่ตัวเลข 5 หลัก แถวที่ {row}: รหัสไปรษณีย์ต้องเป็นตัวเลข 5 หลัก
ERR-015 คะแนนไม่เป็นจำนวนเต็ม ≥ 0 แถวที่ {row}: ค่าในคอลัมน์ "{column_name}" ต้องเป็นจำนวนเต็มที่มากกว่าหรือเท่ากับ 0
ERR-016 ยอดใช้จ่ายไม่เป็นตัวเลข ≥ 0 แถวที่ {row}: ยอดใช้จ่ายสะสมต้องเป็นตัวเลขที่มากกว่าหรือเท่ากับ 0
ERR-017 ระดับ Rank ไม่มีในระบบ แถวที่ {row}: ไม่พบระดับ Rank "{rank}" ในระบบ กรุณาตรวจสอบ
ERR-018 ไฟล์ไม่มีข้อมูล (เฉพาะ Header) ไฟล์ไม่มีข้อมูลสำหรับ Import กรุณาเพิ่มข้อมูลอย่างน้อย 1 แถว
ERR-019 รูปแบบไฟล์ไม่ถูกต้อง รูปแบบไฟล์ไม่ถูกต้อง กรุณาใช้ Template ที่กำหนด

6. ขั้นตอนการทำงานของระบบ

ลำดับการทำงานเมื่อผู้ใช้กด Import ไฟล์สมาชิกเข้าสู่ระบบ:

1

ตรวจสอบรูปแบบไฟล์

ไฟล์ต้องเป็น .xlsx เท่านั้น

2

ตรวจสอบ Header

Header ต้องตรงกับ Template ที่กำหนด

3

ตรวจสอบข้อมูลทีละแถว

• เบอร์โทรศัพท์ (บังคับ) ต้องมีค่าและรูปแบบถูกต้อง
• เบอร์โทรศัพท์ห้ามซ้ำในไฟล์และในระบบ
• อีเมล (ถ้ามี) ต้องรูปแบบถูกต้อง
• วันที่ (ถ้ามี) ต้องรูปแบบถูกต้อง + วันเกิดไม่เป็นอนาคต
• คอลัมน์ตัวเลือกต้องตรงกับค่าที่ระบบรองรับ
• ที่อยู่ต้องสัมพันธ์กัน (จังหวัด → เขต/อำเภอ → แขวง/ตำบล)
• ตัวเลข (คะแนน, ยอดใช้จ่าย) ต้อง ≥ 0

4

แสดงผลลัพธ์

✗ พบ Error → แสดงรายการ Error ทั้งหมด (ไม่ Import ข้อมูลใดๆ)
✓ ไม่มี Error → สร้างสมาชิกใหม่ทั้งหมดเข้าระบบ

7. หมายเหตุสำคัญ

gavel
All or Nothing: ระบบจะทำการ Validate ข้อมูลทั้งหมดก่อน หากมี Error แม้แต่ 1 แถว จะไม่ดำเนินการ Import ทั้งไฟล์
block
Create Only: ระบบรองรับเฉพาะการสร้างสมาชิกใหม่ หากเบอร์โทรศัพท์ซ้ำกับสมาชิกเดิมจะแสดง Error ไม่อัพเดททับ
lightbulb
ค่าว่าง: คอลัมน์ที่ไม่ใส่ค่า — Number จะเป็น 0, Text/Date จะเป็นค่าว่าง
list_alt
ตัวเลือก (Dropdown): คอลัมน์ที่เป็นตัวเลือก ต้องใส่ค่าตรงตัวตามที่ระบบกำหนดเท่านั้น ห้ามใส่ค่าอื่นที่ไม่อยู่ในรายการ
phone_android
เบอร์โทรศัพท์ = Key: เบอร์โทรศัพท์เป็นข้อมูลหลักในการระบุตัวตนสมาชิก ต้องไม่ซ้ำทั้งในไฟล์และในระบบ
