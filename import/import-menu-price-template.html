1. ภาพรวม

ระบบรองรับการ Import ข้อมูลราคาเมนูในแต่ละช่องทางการขายแบบ Bulk ผ่านไฟล์ Excel (.xlsx) เพื่อให้ผู้ใช้สามารถอัพเดทราคาเมนูจำนวนมากได้ในคราวเดียว โดยไม่ต้องแก้ไขทีละรายการในระบบ

info
วัตถุประสงค์: ลดเวลาในการอัพเดทราคาเมนูหลายรายการพร้อมกัน และรองรับหลายช่องทางการขายในครั้งเดียว

2. โครงสร้างคอลัมน์ใน Template

ตารางด้านล่างแสดงคอลัมน์ทั้งหมดที่อยู่ใน Template พร้อมระบุว่าคอลัมน์ใดบังคับกรอก

ลำดับ ชื่อคอลัมน์ บังคับกรอก ประเภทข้อมูล คำอธิบาย
1 ชื่อเมนู ✱ บังคับ Text ชื่อเมนูที่ต้องการกำหนดราคา
2 ทานที่ร้าน ✱ บังคับ Number (ทศนิยม 2 ตำแหน่ง) ราคาสำหรับช่องทางทานที่ร้าน
3 กลับบ้าน ไม่บังคับ Number (ทศนิยม 2 ตำแหน่ง) ราคาสำหรับช่องทางกลับบ้าน
4 Grab Food ไม่บังคับ Number (ทศนิยม 2 ตำแหน่ง) ราคาสำหรับช่องทาง Grab Food
5 Lineman ไม่บังคับ Number (ทศนิยม 2 ตำแหน่ง) ราคาสำหรับช่องทาง Lineman
6 Robinhood ไม่บังคับ Number (ทศนิยม 2 ตำแหน่ง) ราคาสำหรับช่องทาง Robinhood
7 Shopee Food ไม่บังคับ Number (ทศนิยม 2 ตำแหน่ง) ราคาสำหรับช่องทาง Shopee Food
lightbulb
หมายเหตุ: สามารถเพิ่มคอลัมน์ช่องทางการขายใหม่ต่อจากคอลัมน์สุดท้ายได้ (ดูรายละเอียดในหัวข้อ 5)

3. ตัวอย่างข้อมูลในไฟล์

ตัวอย่างข้อมูลที่กรอกใน Template สำหรับ Import:

ชื่อเมนู ทานที่ร้าน กลับบ้าน Grab Food Lineman Robinhood Shopee Food
เมนู 1 100.00 — — — — —
เมนู 2 100.00 — — — — —
เมนู 3 100.00 — — — — —
info
ช่องที่แสดง "—" หมายถึงไม่มีข้อมูล (เว้นว่าง) ซึ่งระบบจะไม่อัพเดทราคาในช่องทางนั้น

4. กฎการ Import ข้อมูล

verified 4.1 คอลัมน์บังคับกรอก (Required Fields)

  • ชื่อเมนู — ต้องมีค่าทุกแถว ห้ามเว้นว่าง
  • ทานที่ร้าน — ต้องมีค่าทุกแถว (เป็นราคาหลักของเมนู)

remove_circle_outline 4.2 การไม่ใส่ข้อมูล (Empty Value)

  • คอลัมน์ช่องทางการขายที่ไม่บังคับ หากไม่ใส่ค่า → ไม่อัพเดทข้อมูลในระบบเดิม (ระบบจะคงค่าเดิมไว้)
  • กรณีต้องการลบราคาของช่องทางนั้นออก → ให้ใส่ค่าเป็น 0
warning
สำคัญ: "ไม่ใส่ค่า" ≠ "ใส่ค่า 0" — ไม่ใส่ค่าคือไม่อัพเดท, ใส่ 0 คือลบราคาออก

payments 4.3 เงื่อนไขราคา

  • ราคาต้องเป็นตัวเลขเท่านั้น (รองรับทศนิยม 2 ตำแหน่ง เช่น 100.00, 59.50)
  • ราคาต้องมีค่า ≥ 0 (มากกว่าหรือเท่ากับศูนย์)
  • ห้ามใส่สัญลักษณ์หรือตัวอักษร เช่น ฿, บาท, THB

5. การเพิ่มช่องทางการขายเพิ่มเติม

หากมีช่องทางการขายนอกเหนือจากที่กำหนดใน Template เดิม สามารถเพิ่มคอลัมน์ใหม่ต่อท้ายได้

add_circle เงื่อนไขการเพิ่มช่องทาง

  • ชื่อคอลัมน์ต้องตรงกับชื่อช่องทางการขายที่มีอยู่ในระบบ (ตัวพิมพ์เล็ก-ใหญ่ต้องตรงกัน)
  • ประเภทข้อมูลเป็น Number (ทศนิยม 2 ตำแหน่ง) เหมือนช่องทางอื่น
  • หากไม่ใส่ค่า ระบบจะไม่อัพเดทข้อมูลเดิม (เหมือนช่องทางอื่น)
  • หากชื่อคอลัมน์ไม่ตรงกับช่องทางในระบบ → แสดง Error

ตัวอย่าง: เพิ่มช่องทาง "Food Panda" ต่อท้าย

ชื่อเมนู ทานที่ร้าน กลับบ้าน Grab Food ... Food Panda ✨
เมนู 1 100.00 — — ... 120.00

6. รายการ Error Messages

เมื่อข้อมูลไม่ผ่านการตรวจสอบ ระบบจะแจ้งเตือน Error ตามรายการด้านล่าง โดยระบุแถวที่พบปัญหาให้ชัดเจน

error
หลักการ All or Nothing: หากพบ Error แม้แต่ 1 รายการ ระบบจะไม่ทำการ Import ข้อมูลทั้งไฟล์ และแสดง Error ทั้งหมดให้แก้ไข
รหัส เงื่อนไขที่ทำให้เกิด Error ข้อความแจ้งเตือน
ERR-001 ชื่อเมนูเป็นค่าว่าง แถวที่ {row}: กรุณาระบุชื่อเมนู (ชื่อเมนูเป็นข้อมูลบังคับ)
ERR-002 ทานที่ร้านเป็นค่าว่าง แถวที่ {row}: กรุณาระบุราคาทานที่ร้าน (ราคาทานที่ร้านเป็นข้อมูลบังคับ)
ERR-003 ราคาไม่เป็นตัวเลข แถวที่ {row}: ราคาในคอลัมน์ "{column_name}" ต้องเป็นตัวเลขเท่านั้น
ERR-004 ราคามีค่าน้อยกว่า 0 แถวที่ {row}: ราคาในคอลัมน์ "{column_name}" ต้องมีค่ามากกว่าหรือเท่ากับ 0
ERR-005 ชื่อเมนูไม่มีอยู่ในระบบ แถวที่ {row}: ไม่พบเมนู "{menu_name}" ในระบบ กรุณาตรวจสอบ
ERR-006 ชื่อเมนูซ้ำในไฟล์ แถวที่ {row}: ชื่อเมนู "{menu_name}" ซ้ำกับแถวที่ {duplicate_row}
ERR-007 ไฟล์ไม่มีข้อมูล (เฉพาะ Header) ไฟล์ไม่มีข้อมูลสำหรับ Import กรุณาเพิ่มข้อมูลอย่างน้อย 1 แถว
ERR-008 รูปแบบไฟล์ไม่ถูกต้อง รูปแบบไฟล์ไม่ถูกต้อง กรุณาใช้ Template ที่กำหนด
ERR-009 ชื่อคอลัมน์ช่องทางการขายไม่มีในระบบ ไม่พบช่องทางการขาย "{column_name}" ในระบบ กรุณาตรวจสอบชื่อให้ตรงกับที่ตั้งค่าไว้

7. ขั้นตอนการทำงานของระบบ

ลำดับการทำงานเมื่อผู้ใช้กด Import ไฟล์เข้าสู่ระบบ:

1

ตรวจสอบรูปแบบไฟล์

ไฟล์ต้องเป็น .xlsx เท่านั้น

2

ตรวจสอบ Header

Header ต้องตรงกับ Template + ช่องทางเพิ่มเติมต้องมีอยู่ในระบบ

3

ตรวจสอบข้อมูลทีละแถว

• คอลัมน์บังคับ (ชื่อเมนู, ทานที่ร้าน) ต้องมีค่า
• ราคาต้องเป็นตัวเลข ≥ 0
• ชื่อเมนูต้องไม่ซ้ำในไฟล์
• ชื่อเมนูต้องมีอยู่ในระบบ

4

แสดงผลลัพธ์

✗ พบ Error → แสดงรายการ Error ทั้งหมด (ไม่ Import ข้อมูลใดๆ)
✓ ไม่มี Error → ดำเนินการ Import และอัพเดทราคาทั้งหมด

8. หมายเหตุสำคัญ

gavel
All or Nothing: ระบบจะทำการ Validate ข้อมูลทั้งหมดก่อน หากมี Error แม้แต่ 1 แถว จะไม่ดำเนินการ Import ทั้งไฟล์
shield
ป้องกันการเขียนทับ: คอลัมน์ช่องทางที่ไม่ได้ใส่ราคา จะไม่ถูกอัพเดท เพื่อป้องกันการเขียนทับข้อมูลเดิมโดยไม่ตั้งใจ
calculate
รูปแบบตัวเลข: รองรับทศนิยม 2 ตำแหน่ง (เช่น 100.00, 59.50)
add_circle
ช่องทางเพิ่มเติม: สามารถเพิ่มช่องทางการขายใหม่ได้ โดยเพิ่มคอลัมน์ต่อท้าย และชื่อต้องตรงกับในระบบ
