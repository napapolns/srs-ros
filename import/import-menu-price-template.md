# Template Import ราคาเมนู - ช่องทางการขาย

## 1. ภาพรวม

Template สำหรับ Import ข้อมูลราคาเมนูในแต่ละช่องทางการขายเข้าสู่ระบบ รองรับการอัพเดทราคาแบบ Bulk ผ่านไฟล์ Excel (.xlsx)

- **ระดับการเปลี่ยนแปลง:** ระดับสาขา (Branch Level) — ราคาที่ Import จะมีผลเฉพาะสาขาที่เลือกดำเนินการ
- **ประเภทการทำงาน:** อัพเดทข้อมูลในระบบ (Update Only) — เมนูที่ระบุต้องมีอยู่ในระบบแล้ว
- **ช่องทางการใช้งาน:** ทำผ่านระบบ Web Admin

## 4. กฎการ Import ข้อมูล

### 4.1 คอลัมน์บังคับกรอก (Required Fields)

| คอลัมน์ | เงื่อนไข |
|---------|---------|
| ชื่อเมนู | ต้องมีค่าทุกแถว |
| ทานที่ร้าน | ต้องมีค่าทุกแถว (ราคาหลักของเมนู) |

### 4.2 การไม่ใส่ข้อมูล (Empty Value)

- คอลัมน์ช่องทางการขายที่ไม่บังคับ หากไม่ใส่ค่า → **ไม่อัพเดทข้อมูลในระบบเดิม** (ระบบจะคงค่าเดิมไว้)
- กรณีต้องการลบราคาของช่องทางนั้นออก → ใส่ค่าเป็น `0`

### 4.3 เงื่อนไขราคา

- ต้องเป็นตัวเลขเท่านั้น (รองรับทศนิยม 2 ตำแหน่ง)
- ต้องมีค่า ≥ 0
- ห้ามใส่สัญลักษณ์หรือตัวอักษร (เช่น ฿, บาท, THB)

## 5. การเพิ่มช่องทางการขายเพิ่มเติม

หากมีช่องทางการขายนอกเหนือจาก Template เดิม สามารถ **เพิ่มคอลัมน์ใหม่ต่อท้าย** ได้ โดยมีเงื่อนไข:

| เงื่อนไข | รายละเอียด |
|---------|-----------|
| ชื่อคอลัมน์ | ต้องตรงกับชื่อช่องทางการขายที่มีอยู่ในระบบ (ตัวพิมพ์เล็ก-ใหญ่ต้องตรงกัน) |
| ประเภทข้อมูล | Number (ทศนิยม 2 ตำแหน่ง) เหมือนช่องทางอื่น |
| การไม่ใส่ค่า | ไม่อัพเดทข้อมูลในระบบเดิม (เหมือนช่องทางอื่น) |

### ตัวอย่างการเพิ่มช่องทาง

|----------|:-----------:|:--------:|:---------:|:---:|:--------------:|:---------------:|
| เมนู 1 | 100.00 | | | | 120.00 | 110.00 |

## 6. Error Messages

รายการข้อผิดพลาดที่ระบบจะแจ้งเตือนเมื่อ Import ไม่ผ่านการตรวจสอบ:

| รหัส | เงื่อนไข | ข้อความแจ้งเตือน |
|:----:|---------|----------------|
| ERR-001 | ชื่อเมนูเป็นค่าว่าง | `แถวที่ {row}: กรุณาระบุชื่อเมนู (ชื่อเมนูเป็นข้อมูลบังคับ)` |
| ERR-002 | ทานที่ร้านเป็นค่าว่าง | `แถวที่ {row}: กรุณาระบุราคาทานที่ร้าน (ราคาทานที่ร้านเป็นข้อมูลบังคับ)` |
| ERR-003 | ราคาไม่เป็นตัวเลข | `แถวที่ {row}: ราคาในคอลัมน์ "{column_name}" ต้องเป็นตัวเลขเท่านั้น` |
| ERR-004 | ราคามีค่าน้อยกว่า 0 | `แถวที่ {row}: ราคาในคอลัมน์ "{column_name}" ต้องมีค่ามากกว่าหรือเท่ากับ 0` |
| ERR-005 | ชื่อเมนูไม่มีอยู่ในระบบ | `แถวที่ {row}: ไม่พบเมนู "{menu_name}" ในระบบ กรุณาตรวจสอบ` |
| ERR-006 | ชื่อเมนูซ้ำในไฟล์ | `แถวที่ {row}: ชื่อเมนู "{menu_name}" ซ้ำกับแถวที่ {duplicate_row}` |
| ERR-007 | ไฟล์ไม่มีข้อมูล (เฉพาะ Header) | `ไฟล์ไม่มีข้อมูลสำหรับ Import กรุณาเพิ่มข้อมูลอย่างน้อย 1 แถว` |
| ERR-008 | รูปแบบไฟล์ไม่ถูกต้อง | `รูปแบบไฟล์ไม่ถูกต้อง กรุณาใช้ Template ที่กำหนด` |
| ERR-009 | ชื่อคอลัมน์ช่องทางการขายไม่มีในระบบ | `ไม่พบช่องทางการขาย "{column_name}" ในระบบ กรุณาตรวจสอบชื่อให้ตรงกับที่ตั้งค่าไว้` |

## 7. ขั้นตอนการทำงานของระบบ

```text
1. ตรวจสอบรูปแบบไฟล์ → ต้องเป็น .xlsx
2. ตรวจสอบ Header → ตรงกับ Template + ช่องทางเพิ่มเติมต้องมีในระบบ
3. ตรวจสอบข้อมูลทีละแถว:
   a. คอลัมน์บังคับ (ชื่อเมนู, ทานที่ร้าน) ต้องมีค่า
   b. ราคาต้องเป็นตัวเลข ≥ 0
   c. ชื่อเมนูต้องไม่ซ้ำในไฟล์
   d. ชื่อเมนูต้องมีอยู่ในระบบ
4. ผลลัพธ์:
   ✗ พบ Error → แสดงรายการ Error ทั้งหมด (ไม่ Import ข้อมูลใดๆ)
   ✓ ไม่มี Error → ดำเนินการ Import และอัพเดทราคา
```

---

## 8. หมายเหตุ

- ระบบใช้หลัก **All or Nothing** — หากมี Error แม้แต่ 1 แถว จะไม่ดำเนินการ Import ทั้งไฟล์
- คอลัมน์ช่องทางที่ไม่ได้ใส่ราคา จะไม่ถูกอัพเดท เพื่อป้องกันการเขียนทับข้อมูลเดิมโดยไม่ตั้งใจ
- รองรับทศนิยม 2 ตำแหน่ง (เช่น 100.00, 59.50)
- สามารถเพิ่มช่องทางการขายใหม่ได้ โดยเพิ่มคอลัมน์ต่อท้าย และชื่อต้องตรงกับในระบบ
