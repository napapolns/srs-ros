# Template Import สมาชิก (Member)

## 1. ภาพรวม

Template สำหรับ Import ข้อมูลสมาชิกเข้าสู่ระบบแบบ Bulk ผ่านไฟล์ Excel (.xlsx) เพื่อให้สามารถเพิ่มสมาชิกใหม่จำนวนมากได้ในคราวเดียว

- **ประเภทการทำงาน:** สร้างสมาชิกใหม่เท่านั้น (Create Only) — ไม่รองรับการอัพเดทข้อมูลสมาชิกที่มีอยู่แล้ว
- หากเบอร์โทรศัพท์ซ้ำกับสมาชิกในระบบ จะแสดง Error และไม่ดำเนินการ Import

## 4. กฎการ Import ข้อมูล

### 4.1 คอลัมน์บังคับกรอก (Required Fields)

| คอลัมน์ | เงื่อนไข |
|---------|---------|
| เบอร์โทรศัพท์ | ต้องมีค่าทุกแถว (ใช้เป็น Key หลักในการระบุตัวตนสมาชิก) |

### 4.2 การไม่ใส่ข้อมูล (Empty Value)

- คอลัมน์ที่ไม่บังคับ หากไม่ใส่ค่า:
  - **ข้อมูลประเภท Number** → ค่าในระบบจะเป็น `0`
  - **ข้อมูลประเภท Text / Date** → ค่าในระบบจะเป็นค่าว่าง (empty)

### 4.3 เงื่อนไขเบอร์โทรศัพท์

- ต้องเป็นตัวเลข 10 หลัก ไม่มีขีด (เช่น `0901234567`)
- ต้องขึ้นต้นด้วย `0`
- ห้ามมีตัวอักษร สัญลักษณ์ หรือขีด `-`
- ห้ามซ้ำกับเบอร์โทรศัพท์อื่นในไฟล์เดียวกัน
- ห้ามซ้ำกับเบอร์โทรศัพท์ที่มีอยู่ในระบบแล้ว (กรณีเพิ่มสมาชิกใหม่)

### 4.4 เงื่อนไขอีเมล

- ต้องเป็นรูปแบบ Email ที่ถูกต้อง (มี `@` และ domain)
- หากใส่ค่า ต้อง validate format

### 4.5 เงื่อนไขวันที่ (วันเกิด / วันสมัครสมาชิก)

- ต้องเป็นรูปแบบ `DD/MM/YYYY` เท่านั้น
- วันที่ต้องเป็นวันที่จริง (เช่น ไม่มี 31/02/2026)
- วันเกิดต้องไม่เป็นวันในอนาคต

### 4.6 เงื่อนไขข้อมูลที่เป็นตัวเลือก (Dropdown Values)

สำหรับคอลัมน์ที่มีรายการตัวเลือกกำหนดไว้ ค่าที่ใส่ต้อง **ตรงตัวกับตัวเลือกที่ระบบรองรับ** ดังนี้:

| คอลัมน์ | ตัวเลือกที่ยอมรับ |
|---------|-----------------|
| เพศ | `ชาย`, `หญิง`, `ไม่ระบุ` |
| อาชีพ | `พนักงานบริษัท`, `ข้าราชการ`, `ธุรกิจส่วนตัว`, `นักเรียน/นักศึกษา`, `อื่นๆ` |
| รายได้ | `น้อยกว่า 15,000 บาท`, `15,000 - 30,000 บาท`, `30,001 - 50,000 บาท`, `มากกว่า 50,000 บาท` |
| สถานะภาพ | `โสด`, `สมรส`, `หม้าย`, `หย่า` |
| ระดับการศึกษา | `ต่ำกว่ามัธยม`, `มัธยม`, `ปวช./ปวส.`, `ปริญญาตรี`, `ปริญญาโท`, `ปริญญาเอก`, `อื่นๆ` |
| การรับข้อมูลข่าวสาร | `Line`, `SMS`, `Email`, `ไม่รับข่าวสาร` |

> **หมายเหตุ:** ค่าที่ใส่ต้องตรงตัวอักษร (case-sensitive) ตามรายการด้านบน หากใส่ค่าที่ไม่ตรงกับตัวเลือก ระบบจะแสดง Error

### 4.7 เงื่อนไขที่อยู่ (จังหวัด / เขต-อำเภอ / แขวง-ตำบล)

- จังหวัด, เขต/อำเภอ, แขวง/ตำบล เป็นการ **พิมพ์เอง** แต่ค่าที่ใส่ต้องตรงกับข้อมูลในระบบ
- จังหวัดต้องตรงกับรายชื่อจังหวัดในระบบ
- เขต/อำเภอ ต้องอยู่ภายใต้จังหวัดที่ระบุ
- แขวง/ตำบล ต้องอยู่ภายใต้เขต/อำเภอที่ระบุ
- หากระบุเขต/อำเภอ โดยไม่ระบุจังหวัด → แสดง Error
- หากระบุแขวง/ตำบล โดยไม่ระบุเขต/อำเภอ → แสดง Error

### 4.8 เงื่อนไขรหัสไปรษณีย์

- ต้องเป็นตัวเลข 5 หลักเท่านั้น

### 4.9 เงื่อนไขคะแนนและยอดใช้จ่าย

- คะแนนคงเหลือ / คะแนนสะสม → ต้องเป็นจำนวนเต็ม ≥ 0
- ยอดใช้จ่ายสะสม → ต้องเป็นตัวเลข ≥ 0 (ทศนิยม 2 ตำแหน่ง)

### 4.10 เงื่อนไขระดับ Rank

- ค่าที่ใส่ต้องตรงกับชื่อระดับ Rank ที่ตั้งค่าไว้ในระบบ
- หากไม่ใส่ค่า ระบบจะเก็บเป็นค่าว่าง (ไม่กำหนด Rank)

## 5. Error Messages

รายการข้อผิดพลาดที่ระบบจะแจ้งเตือนเมื่อ Import ไม่ผ่านการตรวจสอบ:

| รหัส | เงื่อนไข | ข้อความแจ้งเตือน |
|:----:|---------|----------------|
| ERR-001 | เบอร์โทรศัพท์เป็นค่าว่าง | `แถวที่ {row}: กรุณาระบุเบอร์โทรศัพท์ (เบอร์โทรศัพท์เป็นข้อมูลบังคับ)` |
| ERR-002 | เบอร์โทรศัพท์รูปแบบไม่ถูกต้อง | `แถวที่ {row}: รูปแบบเบอร์โทรศัพท์ไม่ถูกต้อง (ต้องเป็นตัวเลข 10 หลัก ไม่มีขีด)` |
| ERR-003 | เบอร์โทรศัพท์ซ้ำในไฟล์ | `แถวที่ {row}: เบอร์โทรศัพท์ "{phone}" ซ้ำกับแถวที่ {duplicate_row}` |
| ERR-004 | เบอร์โทรศัพท์ซ้ำกับในระบบ | `แถวที่ {row}: เบอร์โทรศัพท์ "{phone}" มีอยู่ในระบบแล้ว` |
| ERR-005 | อีเมลรูปแบบไม่ถูกต้อง | `แถวที่ {row}: รูปแบบอีเมลไม่ถูกต้อง` |
| ERR-006 | วันที่รูปแบบไม่ถูกต้อง | `แถวที่ {row}: รูปแบบวันที่ในคอลัมน์ "{column_name}" ไม่ถูกต้อง (ต้องเป็น DD/MM/YYYY)` |
| ERR-007 | วันเกิดเป็นวันในอนาคต | `แถวที่ {row}: วันเกิดต้องไม่เป็นวันที่ในอนาคต` |
| ERR-008 | ค่าตัวเลือกไม่ตรงกับที่ระบบรองรับ | `แถวที่ {row}: ค่า "{value}" ในคอลัมน์ "{column_name}" ไม่ตรงกับตัวเลือกที่รองรับ` |
| ERR-009 | จังหวัดไม่มีในระบบ | `แถวที่ {row}: ไม่พบจังหวัด "{province}" ในระบบ` |
| ERR-010 | เขต/อำเภอไม่ตรงกับจังหวัด | `แถวที่ {row}: เขต/อำเภอ "{district}" ไม่อยู่ภายใต้จังหวัด "{province}"` |
| ERR-011 | แขวง/ตำบลไม่ตรงกับเขต/อำเภอ | `แถวที่ {row}: แขวง/ตำบล "{sub_district}" ไม่อยู่ภายใต้เขต/อำเภอ "{district}"` |
| ERR-012 | ระบุเขต/อำเภอโดยไม่ระบุจังหวัด | `แถวที่ {row}: กรุณาระบุจังหวัดก่อนระบุเขต/อำเภอ` |
| ERR-013 | ระบุแขวง/ตำบลโดยไม่ระบุเขต/อำเภอ | `แถวที่ {row}: กรุณาระบุเขต/อำเภอก่อนระบุแขวง/ตำบล` |
| ERR-014 | รหัสไปรษณีย์ไม่ใช่ตัวเลข 5 หลัก | `แถวที่ {row}: รหัสไปรษณีย์ต้องเป็นตัวเลข 5 หลัก` |
| ERR-015 | คะแนนไม่เป็นจำนวนเต็ม ≥ 0 | `แถวที่ {row}: ค่าในคอลัมน์ "{column_name}" ต้องเป็นจำนวนเต็มที่มากกว่าหรือเท่ากับ 0` |
| ERR-016 | ยอดใช้จ่ายไม่เป็นตัวเลข ≥ 0 | `แถวที่ {row}: ยอดใช้จ่ายสะสมต้องเป็นตัวเลขที่มากกว่าหรือเท่ากับ 0` |
| ERR-017 | ระดับ Rank ไม่มีในระบบ | `แถวที่ {row}: ไม่พบระดับ Rank "{rank}" ในระบบ กรุณาตรวจสอบ` |
| ERR-018 | ไฟล์ไม่มีข้อมูล (เฉพาะ Header) | `ไฟล์ไม่มีข้อมูลสำหรับ Import กรุณาเพิ่มข้อมูลอย่างน้อย 1 แถว` |
| ERR-019 | รูปแบบไฟล์ไม่ถูกต้อง | `รูปแบบไฟล์ไม่ถูกต้อง กรุณาใช้ Template ที่กำหนด` |

## 6. ขั้นตอนการทำงานของระบบ

```text
1. ตรวจสอบรูปแบบไฟล์ → ต้องเป็น .xlsx
2. ตรวจสอบ Header → ตรงกับ Template หรือไม่
3. ตรวจสอบข้อมูลทีละแถว:
   a. เบอร์โทรศัพท์ (บังคับ) ต้องมีค่าและรูปแบบถูกต้อง
   b. เบอร์โทรศัพท์ต้องไม่ซ้ำในไฟล์และในระบบ
   c. อีเมล (ถ้ามี) ต้องรูปแบบถูกต้อง
   d. วันที่ (ถ้ามี) ต้องรูปแบบถูกต้อง + วันเกิดไม่เป็นอนาคต
   e. คอลัมน์ตัวเลือก ต้องตรงกับค่าที่ระบบรองรับ
   f. ที่อยู่ต้องสัมพันธ์กัน (จังหวัด → เขต/อำเภอ → แขวง/ตำบล)
   g. ตัวเลข (คะแนน, ยอดใช้จ่าย) ต้อง ≥ 0
4. ผลลัพธ์:
   ✗ พบ Error → แสดงรายการ Error ทั้งหมด (ไม่ Import ข้อมูลใดๆ)
   ✓ ไม่มี Error → ดำเนินการ Import สมาชิกเข้าระบบ
```

## 7. หมายเหตุ

- ระบบใช้หลัก **All or Nothing** — หากมี Error แม้แต่ 1 แถว จะไม่ดำเนินการ Import ทั้งไฟล์
- **เบอร์โทรศัพท์** เป็น Key หลัก หากเบอร์ซ้ำกับสมาชิกที่มีอยู่แล้ว → ระบบจะแสดง Error (ไม่อัพเดททับ)
- คอลัมน์ที่ไม่ใส่ค่า: Number → `0`, Text/Date → ค่าว่าง
- คอลัมน์ที่เป็นตัวเลือก (Dropdown) ต้องใส่ค่าตรงตัวตามที่ระบบกำหนด ห้ามใส่ค่าอื่นที่ไม่อยู่ในรายการ
- รองรับทศนิยม 2 ตำแหน่งสำหรับยอดใช้จ่ายสะสม (เช่น 100.00, 2500.50)
